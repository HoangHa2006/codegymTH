CSS Flexbox là gì?

Flexbox là mô hình bố cục CSS giúp sắp xếp các phần tử theo hàng hoặc cột, phân chia không gian và căn chỉnh nội dung một cách linh hoạt.

Thiết kế Responsive

Media Queries cho phép thay đổi bố cục theo kích thước màn hình. Khi màn hình nhỏ, Sidebar sẽ chuyển xuống dưới phần nội dung chính.

Ưu điểm của Flexbox

Code dễ hiểu, dễ bảo trì, hỗ trợ căn chỉnh linh hoạt và giúp website hiển thị tốt trên nhiều thiết bị.
